# Hurry-Go-Round v0.1.0 Gameplay Scope

## Purpose

v0.1.0 establishes the browser-game platform and validates responsive player movement before production gameplay systems are introduced.

## Included

- An original placeholder map larger than many viewports.
- An original geometric placeholder player.
- Eight-direction movement using WASD, arrow keys, or a pointer/touch drag.
- Equalized diagonal and cardinal movement speeds.
- Player confinement within the map and a camera that follows the player.
- A canvas that adapts to desktop, mobile, portrait, and landscape viewport sizes.

## Explicitly excluded

This release does not include harvesting, customers, selling, workers, upgrades, persistence, scenarios, audio, a backend, authentication, analytics, advertising, external APIs, installability, offline support, a PWA, or a service worker.

## Acceptance criteria

1. The game loads from the Vite development server and the production bundle.
2. Keyboard and touch/pointer input move the same player.
3. The player cannot cross any map edge.
4. Resizing or changing orientation fills the available viewport without reloading.
5. Pure movement behavior has automated tests and the strict TypeScript build passes.
