# Hurry-Go-Round v0.7.0 — Persistent Farm & Contract Board

v0.7.0 incrementally extends v0.6.0 from main commit `db1e0654b5b8dbe1115735634af2337d9b73033f`. The Pages base remains `/hurry-go-round/` and the game retains Phaser, TypeScript, browser APIs, and local primitive artwork as its only runtime platform.

## Persistence

The native IndexedDB database `hurry-go-round-db` (version 1) contains `saves`, `settings`, and `metadata` stores. `primary` and `backup` save keys use schema-1 envelopes with a stable farm ID, UTC timestamps, game version, canonical payload, and Web Crypto SHA-256 checksum. Before a new primary is written, a valid old primary is copied to backup; startup validates primary then recovers from backup. Save failures retain the live farm.

Only canonical values are persisted: player position/facing, resource-keyed cargo/barn/market, economy, unlocks, livestock and its active remaining timer, upgrades, durable worker cargo, wheat/corn crates, stable crop IDs and active remaining times, contracts, progression flags, statistics, play time, and sequence. Legacy scalar inventory mirrors, Phaser objects, customers, routes, pointer state, and UI objects are excluded. Workers restart at authored safe tasks selected from cargo; customers restart with an empty queue. Closed wall-clock time never advances crops, poultry, workers, customers, or contracts.

Dirty farms autosave every 15 seconds. Major contract events request a debounced priority save; page hiding and page exit make a best-effort request. The management menu supports manual save. Settings are independently validated and saved before farm loading. JSON exports are formatted, checksummed envelopes named `hurry-go-round-save-YYYYMMDD-HHMMSS.json`; imports are limited to 2 MiB, fully validated, previewed, confirmed, and atomically activated with the prior primary backed up.

## Delivery contracts

A wooden `出荷契約` board near the management area exposes a camera-fixed `契約を見る` action using E, Space, click, or touch. Its paused responsive panel maintains three deterministic offers and one active contract. A xorshift32 generator persists its state and sequence; stable IDs use `contract-000001` form. Offers only use unlocked wheat, corn, and egg chains.

Single ranges are wheat 18–42, corn 14–34, egg 6–18; mixed components are 10–28, 8–24, 4–12; priority ranges are 10–22, 8–18, 4–10. Reputation levels begin at 0, 5, 15, and 30 points. Rewards round `resource value × type multiplier × reputation multiplier`, using type multipliers 1.35/1.50/1.45 and reputation multipliers 1.00/1.05/1.10/1.15. Bonuses are 15%/20%/30% within active-play targets; missed targets never remove the base reward.

The physical `契約出荷場` consumes one needed barn unit every 180 ms in wheat → corn → egg round-robin order, skipping unavailable or complete resources. It never consumes player cargo, market stock, crates, feed, or egg storage. Cancellation atomically returns delivered goods. Completion pays the wallet once, updates reputation and statistics, and pauses for acknowledgement. Contract time advances only in active, unpaused gameplay.

## Settings and lifecycle

The title flow loads settings and validated saves before starting the farm, offers continue/new/import/settings actions, and previews save summaries. Pause (Escape, P, or touch button) stops the simulation and isolates world input. Text scale, reduced motion, joystick scale/opacity, contextual hints, export/import, return-to-title, and a two-step reset flow are available. Settings survive farm reset.

Cloud saves, accounts, server sync, offline progression, hard-expiring contracts, new resources, processing, audio, PWA, advertising, rankings, and multiplayer remain deferred.
