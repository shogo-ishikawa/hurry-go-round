# Hurry-Go-Round v0.5.0 — Farm Expansion & First Livestock

## Incremental scope

v0.5.0 extends the v0.4.0 farm at baseline `1b91658a7a972f1991276644e104416f509cf0a0`; it does not recreate Vite, Phaser, workflows, Pages configuration, or the existing wheat automation. The world grows from 2000×1400 to **3000×1900**, preserving the original area and adding an east corn parcel and south chicken parcel.

## State and deterministic logic

`GameState` owns a single-resource `carriedInventory`, resource-keyed `barn`, `market`, capacities and sales, `landExpansion`, `livestock`, and carry level. Legacy wheat fields remain only as compatibility data for v0.4.0 workers. Phaser-free functions validate collection/unloading, carry upgrades, prerequisite land purchases, corn-to-feed and feed-to-egg conversion, egg pickup, per-resource restocking/sales, crop regrowth, and context-hint selection. Failed operations return a reason without charging currency, mixing resources, becoming negative, or exceeding capacity.

## Interaction and presentation

Short click/tap creates a destination. A drag outside the joystick derives a normalized direction from the fixed press origin; it continues past the pointer position, pauses in the dead zone, changes direction live, and clears on release. Keyboard/joystick input has priority, followed by drag and then point navigation. Locked rectangles reject point targets and clamp manual movement before entry.

World labels are reusable wooden `WorldSign` objects. Context messages use one camera-fixed, bounded, fading panel and suppress repeated messages. Resource panels and reserved input rectangles adapt to desktop, landscape phone and portrait phone layouts. Corn, chickens, coop fixtures, gates, locks, feed, eggs, and resource-specific carried cargo are drawn with Phaser primitives and the local palette; no external assets are loaded.

## Compatibility and exclusions

Harvest and transport workers remain wheat-only. Market restocking does not depend on player or worker cargo. Existing manual wheat, upgrades, customers, till collection and automation remain active. Cattle, pigs, sheep, animal lifecycle/variation, new worker roles, processing, recipes, seasons/weather, agronomy systems, persistence/PWA/offline progress, audio, accounts/cloud/rankings, monetization, external APIs and multiplayer are intentionally excluded.

## Verification

Pure Vitest coverage includes three-resource carrying, carry prices/capacity, land costs/prerequisite/double purchase, corn harvest/regrowth, feed/egg bounds, resource sales/unlocks, guidance priority, continuous drag, wheat automation invariants and responsive input reservation. Release gates are `npm ci --no-audit --no-fund`, `npm run check`, and `npm run build`; generated `dist/` is inspected but not committed.
