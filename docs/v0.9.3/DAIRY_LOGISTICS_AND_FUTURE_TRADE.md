# v0.9.3 酪農物流・スタッフ・将来の行商人互換性

このファイルは、牧草地・牛舎・乳製品工房を、既存の集配ネットワークと自動化へ接続する方法を定義します。

一個ずつ長距離を往復する自動化は禁止します。

# 2. 既存集配スタッフの拡張

既存の集配スタッフは、次のsourceを扱えるようにします。

```text
麦畑集配ボックス
東農地集配ボックス
鶏小屋集配ボックス
牧草地集配ボックス
牛舎集配ボックス
乳製品完成品ボックス
```

## 2.1 配送可能資源

```text
麦
とうもろこし
たまご
干し草
牛乳
バター
チーズ
```

加工品のうち、

```text
小麦粉
コーンミール
パン
コーンブレッド
```

については、既存加工場・倉庫物流を維持します。

## 2.2 配送先ルール

### 干し草

```text
牛舎で餌不足
→ 干し草台を優先

餌が十分
→ 倉庫
```

### 牛乳

```text
乳製品工房が建設済み
かつ
工房入力に空きあり
かつ
牛乳保護在庫を損なわない
→ 乳製品工房

それ以外
→ 倉庫
```

### バター・チーズ

```text
必ず倉庫
```

## 2.3 配送モード

既存の、

```text
自動
加工場優先
倉庫優先
```

へ、酪農を含めます。

### 自動

- 牛舎の緊急餌を最優先
- 進行中契約の必要数を保護
- 市場最低在庫を保護
- 牛乳保護在庫を保護
- 余剰牛乳を乳製品工房へ送る

### 加工場優先

- 緊急餌と契約を保護
- 牛乳保護在庫を残す
- 余剰牛乳を乳製品工房へ優先配送

### 倉庫優先

- 原則として倉庫へ配送
- 干し草台が緊急水準の場合だけ牛舎へ直接配送

## 2.4 一個運搬禁止

集配スタッフの出発条件：

```text
積載上限に到達
sourceが空
900msまとめ待ちが終了
緊急餌不足
加工機械が原料待ち
```

一個積んだ直後に、長距離を出発してはいけません。

# 3. 酪農スタッフ

新職種：

```text
酪農スタッフ
```

雇用価格：

```text
650コイン
```

前提：

```text
牛舎建設済み
```

研修小屋から雇用・研修できます。

牛舎現地にも小さな雇用パッドを置いて構いませんが、同じ純粋取引を使用します。

## 3.1 役割

- 牧草地集配ボックスまたは倉庫から干し草を積む
- 干し草台へ補充
- ミルクタンクから牛乳を回収
- 牛舎集配ボックスまたは倉庫へ運ぶ

## 3.2 優先順位

```text
1. 干し草台が緊急水準以下
2. ミルクタンクが満杯または満杯に近い
3. 干し草台を目標水準へ補充
4. 牛乳が一定量たまったら回収
5. 待機
```

設定：

```ts
cowFeedEmergencyThreshold: 5
cowFeedTarget: 18
milkPickupThreshold: 5
```

## 3.3 積載上限

```text
Lv1 8個
Lv2 12個
Lv3 16個
```

## 3.4 出発条件

```text
積載上限
供給元が空
700msまとめ待ち
緊急補充
タンク満杯
```

## 3.5 状態

公開表示：

```text
未雇用
作業確認中
干し草を積込中
牛舎へ運搬中
餌を補充中
牛乳を回収中
牛乳を運搬中
倉庫へ納品中
集配ボックスへ納品中
餌待ち
牛乳待ち
待機中
```

内部enum名を表示しないでください。

## 3.6 資源混載

酪農スタッフは、一往復で一種類だけ運びます。

```text
干し草
または
牛乳
```

同時に混載しません。

プレイヤーの「持ち物」は混載可能です。

# 4. 乳製品スタッフ

新職種：

```text
乳製品スタッフ
```

雇用価格：

```text
750コイン
```

前提：

```text
乳製品工房建設済み
```

## 4.1 役割

- 倉庫・牛舎集配ボックス・加工場受入ボックスから牛乳を積む
- 乳製品工房へ搬入
- 完成したバターまたはチーズをまとめて回収
- 乳製品完成品ボックスまたは倉庫へ運ぶ

## 4.2 積載上限

```text
Lv1 8個
Lv2 12個
Lv3 16個
```

## 4.3 搬入ルール

工房の選択レシピを確認します。

```text
バター：牛乳2単位ごと
チーズ：牛乳3単位ごと
```

中途半端な量を一個だけ運ぶのではなく、少なくとも一回のレシピが開始できる量を優先します。

例：

```text
チーズ優先
牛乳2個しかない
→ 追加を短時間待つ
→ 追加がなければ倉庫へ戻すか待機
```

永久停止しないでください。

## 4.4 完成品回収

完成品が次のいずれかを満たしたら出発します。

```text
積載上限
output bufferが空になるまで積載
800ms待ち
output buffer満杯
```

## 4.5 状態

```text
牛乳を積込中
工房へ運搬中
牛乳を搬入中
完成品待ち
バターを回収中
チーズを回収中
倉庫へ運搬中
完成品を納品中
入力満杯
出力満杯
待機中
```

# 9. 将来の行商人・市場仕入れ

v0.9.3では行商人NPCを実装しません。

ただし、将来の次の商品を追加できる設計にします。

```text
フルーツ
食肉
調味料
砂糖
装飾品
限定家具
季節アイテム
```

## 9.1 農場資源と外部仕入れ品を区別する

資源metadata：

```ts
sourceKind:
  | "farm"
  | "livestock"
  | "processing"
  | "trade";
```

将来の例：

```text
りんご：trade
ハム：trade
砂糖：trade
```

後から果樹園を追加する場合は、りんごのsourceKindを複数sourceへ拡張可能にします。

## 9.2 食肉の方針

農場内の牛・鶏を減らして食肉を作る仕組みは導入しません。

食肉は将来、次の経路で取得します。

```text
行商人
交易市場
特別契約報酬
外部農場との交換
```

農場内の家畜と、食肉資源を直接関連付けないでください。

## 9.3 装飾品はResourceAmountsへ入れない

装飾品は、消費資源と別の型を持ちます。

```ts
interface DecorationInventory {
  owned: Record<DecorationId, number>;
  placed: PlacedDecoration[];
}
```

次へ混ぜないでください。

```text
ResourceId
ResourceAmounts
市場食料棚
加工レシピ入力
```

## 9.4 将来の商店interface

v0.9.3では実装不要ですが、次の概念を仕様へ残します。

```ts
interface TradeOffer {
  id: string;
  itemKind: "resource" | "decoration";
  itemId: string;
  quantity: number;
  coinCost: number;
  availableUntil?: number;
  prerequisite?: string;
}
```

# 10. 純粋ロジック

最低限、次に相当する関数を実装します。

```ts
selectDairyTask(...)
getHayDeliveryAmount(...)
getMilkPickupAmount(...)
getDairyInputBatch(...)
getDairyOutputBatch(...)
selectCollectionDestination(...)
canSendMilkToWorkshop(...)

```

要件：

- Phaser非依存
- 決定的
- 負数なし
- 容量超過なし
- 失敗理由を返す
- 入力を予期せず変更しない
- 他資源を変更しない

# 11. 自動テスト

## 酪農スタッフ

- 未雇用で動かない
- 餌緊急時を最優先
- 干し草だけを積む
- 牛乳だけを回収
- 混載しない
- 積載上限を超えない
- 一個運搬を避ける
- 待ち時間後に部分積載で出発
- source空で出発
- 目的地満杯時に資源を失わない

## 乳製品スタッフ

- 工房未建設で動かない
- レシピ必要数を確認
- 牛乳保護在庫を侵害しない
- 完成品をまとめて回収
- 出力満杯を解消
- バター・チーズを混載しない、または明示的な安全な混載ルールを使う
- 永久停止しない

## 集配

- 干し草緊急配送
- 牛乳加工場優先
- 牛乳倉庫fallback
- バター・チーズは倉庫
- 同時アクセスで負数なし
- 資源総量保存
