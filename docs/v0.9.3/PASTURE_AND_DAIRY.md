# v0.9.3 牧草地・牛舎・乳製品工房

このファイルは、v0.9.3の新しい生産チェーンを定義します。

```text
牧草
→ 干し草
→ 牛の餌
→ 牛乳
→ そのまま販売
または
→ バター・チーズへ加工
```

加工場と保存のリリース阻害問題を修正した後に実装してください。

---

## 1.1 推奨販売価格

```ts

milk: 8

```

干し草は通常市場では販売しません。

`marketCapacity.hay = 0`とし、一般顧客は干し草を要求しません。

牛乳・バター・チーズは通常市場と出荷契約へ追加します。

## 1.2 資源metadata

資源定義へ、最低限次を追加してください。

```ts
interface ResourceDefinition {
  id: ResourceId;
  publicName: string;
  unitPrice: number;
  marketCapacity: number;
  sourceKind: "farm" | "livestock" | "processing" | "trade";
  customerDemand: boolean;
  contractEligible: boolean;
  feedFor?: "chicken" | "cow";
  color: number;
  iconId: string;
}
```

例：

```text
干し草：farm / customerDemand=false / feedFor=cow
牛乳：livestock / customerDemand=true
バター：processing / customerDemand=true
チーズ：processing / customerDemand=true
```

このmetadataは、将来の行商人・輸入食材に備えるためにも使用します。

## 2.2 牛舎区画

# 3. 牧草地

## 3.1 解放条件

```text
加工場用地を購入済み
所持金 1,000コイン以上
```

購入価格：

```text
牧草地用地 1,000コイン
```

加工場の実体化と解放導線が正常に動くことが前提です。

## 3.2 牧草ノード

初期：

```text
24区画
```

第1拡張：

```text
36区画
300コイン
```

第2拡張：

```text
48区画
700コイン
```

## 3.3 成長状態

```ts
type PastureNodeState =
  | "growing"
  | "ready"
  | "cut";
```

再成長：

```text
8〜12秒
```

ノードごとに成長時間を少しずらします。

## 3.4 収穫

プレイヤーが準備完了牧草へ近づくと、自動的に刈り取ります。

```text
牧草1区画
→ 干し草1個
```

干し草は、他資源と同じ「持ち物」へ入ります。

総容量を共有します。

他の商品を持っていても収穫できます。

## 3.5 視覚表現

準備完了：

- 背の高い草
- 柔らかな黄緑
- 風で揺れる
- 花を少量含む

収穫後：

- 短い刈り跡
- 土が少し見える

成長中：

- 中間の高さ

収穫エフェクト：

- 草片
- 小さな干し草束
- 鎌の軌跡

無制限パーティクルを生成しないでください。

# 5. 牛舎

## 5.1 建設条件

```text
牧草地を購入済み
所持金 1,400コイン以上
```

建設価格：

```text
牛舎 1,400コイン
```

## 5.2 牛の頭数

牛舎建設時：

```text
牛1頭
```

追加：

```text
2頭目 550コイン
3頭目 950コイン
```

最大3頭です。

牛の追加購入は、牛舎管理看板または酪農管理画面から行います。

## 5.3 牛の状態

v0.9.3では、過度に複雑な個体管理を行いません。

推奨：

```ts
interface CowState {
  id: string;
  fed: boolean;
  productionRemainingMs: number;
  readyMilk: number;
  activitySeed: number;
}
```

実装しない状態：

- 病気
- 幸福度
- 年齢
- 妊娠
- 繁殖
- 寿命
- 肉への変換

## 5.4 牛の行動

固定された牛舎・放牧区画内で、次を行います。

- 草を食べる
- 水を飲む
- ゆっくり歩く
- 休む
- 牛舎へ入る
- 搾乳位置へ移動する

一般的な経路探索は不要です。

固定ポイントと決定的な行動選択を使います。

# 6. 干し草台

## 6.1 容量

```text
24個
```

## 6.2 手動補充

プレイヤーが干し草を持って補充範囲へ入ると、1個ずつ補充します。

```text
補充間隔 140ms
```

条件：

- 干し草だけを減らす
- 他資源を残す
- 容量を超えない
- 離れると停止
- 0個なら何もしない

## 6.3 表示

遠距離：

- 干し草束の形
- 牛の餌設備だと分かる

中距離：

```text
干し草台
牛の餌を補充できます
```

近距離：

```text
干し草 8 / 24
```

操作中は長い説明を消し、干し草が物理的に増える表示へ切り替えます。

# 7. 牛乳生産

## 7.1 基本ルール

牛1頭につき：

```text
干し草1個
→ 10秒
→ 牛乳1個
```

推奨：

```ts
cowMilkProductionMs: 10000
```

牛ごとに独立した生産タイマーを持ちます。

## 7.2 餌消費

牛が次の生産を開始する時点で、干し草台から1個予約・消費します。

二重消費を防ぎます。

保存中は、次を明示します。

```text
牛ID
生産中か
残り時間
予約済み餌
完成待ち牛乳
```

## 7.3 餌不足

干し草がない場合：

- 生産開始しない
- 牛は待機行動
- 牛舎HUDで「餌不足」
- 干し草台を短く強調
- 同じ警告を毎フレーム表示しない

## 7.4 牛乳完成

完成した牛乳は、ミルクタンクへ1個追加します。

タンク満杯の場合：

- 新しい生産を開始しない
- 完成牛乳を消失させない
- 「ミルクタンクが満杯です」を状態変化時だけ表示

# 8. ミルクタンク

## 8.1 容量

```text
24個
```

## 8.2 手動回収

プレイヤーが回収範囲へ入ると、牛乳を1個ずつ持ち物へ移します。

```text
回収間隔 160ms
```

他資源を持っていても回収できます。

総容量が満杯なら停止します。

## 8.3 視覚

- 銀色または白色のタンク
- 牛乳缶
- 液量ゲージ
- タンク満杯の明確な表示
- 回収側の床面
- 牛乳アイコン

干し草台と同じ色・形を使わないでください。

# 9. 乳製品工房

## 9.1 建設条件

```text
牛舎を建設済み
加工場用地を購入済み
製粉機またはベーカリーのランタイムが正常に動作
所持金 1,000コイン以上
```

建設費：

```text
乳製品工房 1,000コイン
```

加工場区画へ増築します。

製粉機・ベーカリー・集配受入ボックスと重ならないようにします。

## 9.2 外観

- バターチャーン
- チーズ槽
- 牛乳缶
- 木製熟成棚
- 白い石壁または明るい木材
- 青白い日除け
- 入力搬入口
- 完成品受取口

## 9.3 レシピ

### バター

```text
牛乳2
→ 6秒
→ バター1
```

### チーズ

```text
牛乳3
→ 10秒
→ チーズ1
```

## 9.4 運転モード

```text
自動
バターを優先
チーズを優先
停止
```

自動モードは、次を考慮します。

- 牛乳保護在庫
- 市場在庫
- 契約需要
- 工房入力
- 工房出力
- バター在庫
- チーズ在庫
- 生産方針

## 9.5 牛乳保護在庫

初期値：

```text
牛乳 6
```

加工へ使用できる牛乳：

```text
倉庫牛乳
- 市場予約
- 契約予約
- 保護在庫
```

負数にならないようにします。

- 牛乳生産で+1
