# Phase 1 — Dairy & Processing Supply

## 目的

牛舎と加工場について、

- どこへ何を入れるか
- 何個必要か
- 何が何個できたか
- 倉庫からどう補充するか
- スタッフをどう雇い、何を自動化するか

を世界表示と管理画面の両方で明確にします。

## 1. 酪農施設レジストリ

次を一つのauthoritative定義へ集約します。

```ts
interface DairyFacilityDefinition {
  id: DairyFacilityId;
  publicName: string;
  center: Point;
  radius: number;
  visibleRadius: number;
  capacity?: number;
  acceptedResources?: ResourceId[];
  producedResources?: ResourceId[];
}
```

最低限、次を定義します。

- 牧草地購入地点
- 牧草地拡張地点
- 牛舎建設地点
- 牛購入地点
- 干し草台
- ミルクタンク
- 乳製品工房建設地点
- 工房搬入口
- 工房受取口
- 酪農管理板

`DairySystem`内の固定座標と、描画座標と、E2E座標を分離して保持してはいけません。

## 2. 牛舎の物理表示

### 干し草台

牛舎の左側または入口側へ、明確な干し草台を描画します。

常時表示:

```text
干し草台
8 / 24
```

近距離表示:

```text
牛1頭につき干し草1個
1個で牛乳1個を生産
持ち物から補充
倉庫から補充
```

視覚要素:

- 干し草束
- 下向き矢印
- 空・部分・満杯
- 餌不足の警告
- 実際のinteraction半径と一致する表示範囲

### ミルクタンク

牛舎の反対側へ、干し草台と形・色が異なるタンクを描画します。

常時表示:

```text
ミルクタンク
5 / 24
```

近距離表示:

```text
ここから牛乳を回収
持ち物へ回収
倉庫へ送る
```

視覚要素:

- 牛乳缶またはタンク
- 上向き矢印
- 空・部分・満杯
- タンク満杯の警告

## 3. 生産規則の表示

現行ロジックを変更せず、明示します。

```text
牛1頭
干し草1個
→ 10秒
→ 牛乳1個
```

牛舎パネルは次を表示します。

```text
牛 2 / 3
稼働中 2
餌待ち 0
牛に保持中の牛乳 0
干し草台 8 / 24
ミルクタンク 5 / 24
次の牛乳 4.2秒
```

複数の牛が生産中の場合は、最短の残り時間を表示します。

問題状態:

```text
干し草がありません
ミルクタンクが満杯です
牛が牛乳を保持しています
```

内部enumや英語IDを表示しません。

## 4. 牛舎管理画面

新しい酪農管理画面を追加します。

ページ:

```text
概要
牛舎
乳製品工房
スタッフ
```

入力:

- E
- Space
- マウス
- タップ
- キーボードTab / Enter / Space / Escape

短い画面ではページ送りまたはスクロールを使います。

### 牛舎ページの操作

```text
持ち物の干し草を全部補充
倉庫から目標量まで補充
牛乳を持ち物へ回収
牛乳を倉庫へ送る
```

各操作は一回の原子的取引です。

## 5. 倉庫から干し草台へ補充

純粋関数を追加します。

```ts
fillHayRackFromBarn(
  barn,
  hayRack,
  target = 18,
  capacity = 24,
)
```

規則:

- 倉庫の干し草だけを消費
- 通常の目標量は18
- 緊急補充では最大24まで可
- 移動量0ならno-op
- 他の商品を変更しない
- 負数にしない
- 一回の操作で一回だけ保存要求
- 結果に移動量、前後値、理由を含める

結果例:

```text
倉庫から干し草を10個補充しました
干し草台 8 → 18
倉庫 14 → 4
```

## 6. 持ち物からの一括補充・一括回収

現在の一個ずつ処理を置き換えます。

```ts
depositHayBatchFromCargo(...)
collectMilkBatchToCargo(...)
moveMilkTankToBarn(...)
```

### 持ち物から干し草

```text
移動量 =
min(
  持ち物の干し草,
  干し草台の空き
)
```

### 牛乳を持ち物へ

```text
移動量 =
min(
  ミルクタンク,
  持ち物の空き
)
```

### 牛乳を倉庫へ

ミルクタンクの全量を一回で倉庫へ移します。

## 7. 酪農スタッフ

既存の `dairy.dairyWorker` を実ランタイムへ接続します。

雇用:

```text
650コイン
牛舎建設済み
```

研修:

```text
Lv1 → Lv2: 280コイン
Lv2 → Lv3: 620コイン
```

容量:

```text
Lv1 8
Lv2 12
Lv3 16
```

優先順位:

1. 干し草台が5以下なら倉庫から緊急補充
2. ミルクタンクが満杯または20以上なら牛乳回収
3. 干し草台を18まで補充
4. 牛乳が5以上なら回収
5. 待機

出発条件:

- 容量到達
- 供給元が空
- 700msまとめ待ち
- 緊急補充
- タンク満杯

一個だけ積んで長距離を往復してはいけません。

## 8. 乳製品スタッフ

既存の `dairy.workshopWorker` を実ランタイムへ接続します。

雇用:

```text
750コイン
乳製品工房建設済み
```

研修:

```text
Lv1 → Lv2: 360コイン
Lv2 → Lv3: 760コイン
```

容量:

```text
Lv1 8
Lv2 12
Lv3 16
```

役割:

- 倉庫から牛乳をレシピ単位で工房へ搬入
- バター・チーズをまとめて倉庫へ搬出
- protectedMilkを侵害しない
- 入力満杯、出力満杯、原料不足で永久停止しない

## 9. 加工場スタッフの雇用・研修

既存の純粋ロジックをUIへ接続します。

### 製粉スタッフ

```text
雇用 450コイン
Lv1 → Lv2 420コイン
Lv2 → Lv3 900コイン
容量 8 / 12 / 16
前提 製粉機建設済み
```

### 製パンスタッフ

```text
雇用 700コイン
Lv1 → Lv2 650コイン
Lv2 → Lv3 1300コイン
容量 6 / 9 / 12
前提 ベーカリー建設済み
```

UIは `hireProcessingWorker`、`trainProcessingWorker`、`getProcessingWorkerCapacity` を直接使用します。

固定式、

```text
4 + level × 2
```

や別職種の研修価格を表示してはいけません。

スタッフページへ実ボタンを追加します。

```text
雇用
研修
最大レベル
```

操作後も画面を閉じず、次を更新します。

- 所持コイン
- レベル
- 容量
- 公開状態
- 次回価格
- 成功・失敗メッセージ

## 10. 倉庫から加工場へ補充

スタッフ未雇用でも使える手動補助を追加します。

機械ページ:

```text
倉庫から1回分を補充
完成品を倉庫へ移す
```

### 1回分補充

選択中レシピを基準に、不足している原料だけを移します。

例:

```text
小麦粉を選択
製粉機入力 麦0
倉庫 麦7

→ 麦2を製粉機へ
```

自動モードでは、

- 現在開始可能なレシピ
- 選択優先
- round-robin
- 原料不足

をauthoritativeな純粋関数で決定します。

全種類を無差別に入力箱へ詰めてはいけません。

### 完成品を倉庫へ

機械outputの全商品を一回で倉庫へ移します。

## 11. ProcessingWorkerSystemの整理

加工スタッフも、上記の手動取引と同じ純粋関数を使います。

禁止:

- UI用と自動化用で異なる費用・容量
- Tweenだけ動かし、論理的には瞬間移動したことを隠す
- wrong ingredientで入力を満杯にする
- 完成品を回収せず原料だけ運び続ける
- carriedAmountを常に0へ上書きし、保存状態と表示を矛盾させる

最低限の公開状態:

```text
倉庫へ向かっています
原料を積込中
製粉機へ運搬中
原料を搬入中
完成品を回収中
倉庫へ納品中
原料待ち
入力満杯
完成品待ち
待機中
```

## 12. コマンド結果

加工・酪農の操作は構造化します。

```ts
interface FacilityCommandResult {
  changed: boolean;
  message: string;
  reason?: string;
  prioritySaveRequested: boolean;
}
```

一回のボタン操作で一回だけ課金・移動します。

## 13. E2E

最低限、次を追加します。

### 牛舎表示

- 干し草台とミルクタンクの表示位置が異なる
- 数量、容量、規則、次の牛乳時間が読める
- 1920×1080、844×390、390×844、320×568で到達可能

### 倉庫干し草

- 倉庫hay 12、rack 3
- 「倉庫から補充」
- rack 15、barn hay 0
- 他資源不変
- 保存・再読込

### 酪農スタッフ

- 実ボタンで雇用
- 650コインを一回控除
- 倉庫から干し草をまとめて積む
- 干し草台へ補充
- 牛乳をまとめて倉庫へ運ぶ
- Lv2/Lv3容量

### 加工スタッフ

- 製粉スタッフ450、製パンスタッフ700
- 正確な研修価格
- 倉庫からレシピ単位で搬入
- 完成品を倉庫へ搬出
- ボタン再表示でlistener重複なし

Playwrightのsetupはコイン・解放・在庫だけを設定できます。雇用、研修、補充、搬出は実ボタンまたは実interactionを使用します。
