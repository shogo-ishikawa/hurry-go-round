# Hurry-Go-Round v0.9.8
## Facility Clarity, Warehouse Supply & Batch Reliability

v0.9.8 は、v0.9.7 の実機プレイで判明した次の問題を、施設表示・倉庫連携・一括処理・状態機械の四層から修正するリリースです。

- 牛舎の干し草投入場所、必要量、牛乳受取場所、生産状態が分かりにくい
- 倉庫の干し草が牛舎で利用されず、保管する意味がない
- 製粉機・ベーカリーへ倉庫から原料を補充しにくい
- 加工場のスタッフ欄は表示だけで、雇用・研修操作が存在しない
- 集配所や集配ボックスの建設範囲に立つと、前提未達でも進捗が何周も繰り返される
- 麦畑拡張時に作物だけ増え、土・畝・柵の表示が追従しない
- 麦の一時集荷箱付近で運搬スタッフが積荷を持ったまま停止する場合がある
- 倉庫への納品と集配ボックスへの預入・取出が一個ずつで、不要な待ち時間がある

## リリース方針

今回の主眼は新しい商品や土地の追加ではありません。

> 既存施設を見れば状態と操作方法が分かり、倉庫に置いた資源が生産へつながり、各物流が一回の操作で確実に完了する状態

を完成条件とします。

## 実装Phase

### Phase 1 — Dairy & Processing Supply

- 牛舎の干し草台、ミルクタンク、牛ごとの生産状態を明示
- 牛1頭につき「干し草1個 → 10秒 → 牛乳1個」を表示
- 持ち物または倉庫から干し草台へ一括補充
- ミルクタンクから持ち物または倉庫へ一括回収
- 酪農スタッフ・乳製品スタッフの実ランタイム接続
- 製粉スタッフ・製パンスタッフの雇用・研修ボタン
- 倉庫から製粉機・ベーカリーへレシピ単位で補充
- 完成品を倉庫へ一括移送
- 既存のスタッフ状態、機械状態、在庫をschema 9のまま保存

### Phase 2 — Atomic Storage & Collection Construction

- 手持ちの商品を倉庫へ一括納品
- 集配ボックスへ対象資源を一括預入
- 集配ボックスから空き容量まで一括取出
- 一回の操作、一回の状態遷移、一回の保存要求
- 集配所・集配ボックスの建設可否を進捗開始前に判定
- 前提不足・コイン不足・建設済みでは進捗を回さない
- 成功・失敗後は範囲を離れるか状態が変わるまで再実行しない
- マウス、タップ、E、Space、範囲内ホールドへ同じ取引を接続

### Phase 3 — Dynamic Wheat Field & Transport Recovery

- 麦畑の土、畝、柵、予定地を動的な専用Viewへ分離
- 30・42・54株の各段階で表示範囲を即時再描画
- 全作物の見た目を含む境界が、対応する畑グラフィック内に収まることを検証
- 麦運搬スタッフをLv1/2/3の容量6/8/10へ実ランタイム接続
- 一時集荷箱から一括積込、倉庫へ一括荷下ろし
- 既に積載上限以上の商品を持つ旧セーブでも、停止せず倉庫へ向かう
- 一時集荷箱が満杯でも、プレイヤーが空にするまで待つのではなく自律して搬出
- 公開版を0.9.8へ更新

## バージョンと保存

```text
Phase 1: public version 0.9.7 / save schema 9
Phase 2: public version 0.9.7 / save schema 9
Phase 3: public version 0.9.8 / save schema 9
```

新しい永続フィールドは原則追加しません。

現在すでに保存されている次の状態を実ランタイムへ接続します。

```text
processing.millOperator
processing.baker
dairy.dairyWorker
dairy.workshopWorker
```

UIのページ、ホバー、進捗リング、操作済みフラグなどは保存しません。

## 共通完了条件

各Phaseは別の新規Codexタスク、別PRとして実装します。

```bash
npm ci --no-audit --no-fund
npm run check
npm run build
npm run e2e
npx playwright test --workers=1 --retries=0 --repeat-each=2
```

次は合格としません。

- timeoutを増やしただけ
- E2Eをskipした
- retryでだけ成功した
- テスト用ブリッジが在庫や建設状態を直接完成させた
- 表示上だけ直し、実ランタイム取引が以前のまま
- 商品が消失・複製する
- 同じ場所に立つだけで課金や取引が繰り返される
