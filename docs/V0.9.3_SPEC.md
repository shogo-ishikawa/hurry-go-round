# Hurry-Go-Round v0.9.3 — Pasture & Dairy

`docs/v0.9.3/` のリリース仕様を実装する増分更新です。加工場と集配のランタイム接続、保存キューと連番復元を修正し、11資源、牧草地、牛舎、牛乳生産、乳製品工房、バター、チーズおよびschema 5永続化を追加します。

## バランス

- 牧草地: 1,000コイン、24区画。36区画へ300、48区画へ700コイン。
- 牛舎: 1,400コイン。2頭目550、3頭目950コイン。
- 牛乳: 干し草1個、10秒、牛乳1個。タンク容量24。
- バター: 牛乳2個、6秒。チーズ: 牛乳3個、10秒。
- 工房: 1,000コイン。Lv2 600、Lv3 1,300コイン。

既存のPages base `/hurry-go-round/`、v0.9.1の操作、加工、契約、集配データを維持します。
