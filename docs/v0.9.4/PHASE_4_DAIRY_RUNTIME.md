# Phase 4 — Dairy Runtime & Final Release

## 1. 前提

次が`main`へマージ済みであること。

```text
Phase 1: Save Recovery
Phase 2: Processing Runtime
Phase 3: Collection Runtime
```

Phase 4は、最新`main`から新しいCodexタスクとして開始します。

## 2. 目的

v0.9.3で追加された酪農ロジックを、マップ、購入、収穫、動物、加工、スタッフ、市場、契約、集配、保存へ完全接続します。

完了ループ：

```text
牧草地を購入
→ 牧草を収穫して干し草を得る
→ 牛舎を建設
→ 牛を飼う
→ 干し草台へ給餌
→ 牛乳を生産
→ ミルクタンクから回収
→ そのまま販売・契約
または
→ 乳製品工房へ搬入
→ バター・チーズへ加工
→ 市場・契約へ出荷
```

推奨ブランチ：

## 6. 牧草地

### 6.1 購入条件

```text
加工場用地を購入済み
1000コイン
```

加工場を利用できる状態になってから、酪農へ進みます。

### 6.2 未購入表示

- 閉じた木柵
- 草原の輪郭
- 牧草地予定地の看板
- 条件一覧
- 牛舎のシルエット

### 6.3 購入

```text
範囲内1200ms
1000コイン
priority save
```

### 6.4 牧草ノード

```text
Level 0: 24
Level 1: 36
Level 2: 48
```

拡張費：

```text
Level 0 → 1: 300コイン
Level 1 → 2: 700コイン
```

牧草ノードは、

```ts
type PastureNodeState = "growing" | "ready" | "cut";
```

を持ちます。

再成長：

```text
8〜12秒
```

ノードごとにstaggerします。

### 6.5 手動収穫

プレイヤーが近づくと自動収穫します。

```text
牧草1ノード
→ 干し草1個
```

既存の混載「持ち物」へ`hay`を追加します。

持てる数を超えません。

### 6.6 視覚

- 背の低い柔らかな牧草
- 刈取り前後の明確な差
- 風で揺れる
- 刈取り時の葉エフェクト
- 収穫後の短い草
- 拡張地の柵と門

## 7. 牛舎

### 7.1 建設

```text
牧草地購入済み
1400コイン
```

建設時に牛1頭を付属します。

### 7.2 牛の追加

```text
2頭目：550コイン
3頭目：950コイン
最大3頭
```

### 7.3 牛GameObject

各牛は、

- 個別ID
- 白黒・茶白などの見た目差
- 歩行
- 干し草を食べる
- 休む
- 水を飲む
- 牛乳準備完了の視覚表現
- 影

を持ちます。

牛を単なる数値としてのみ実装しません。

### 7.4 牛乳生産

牛1頭ごとに、

```text
干し草1
→ 10秒
→ 牛乳1
```

です。

干し草がない場合は待機します。

ミルクタンク満杯時は、生産完了を保持し、牛乳を消失させません。

### 7.5 readyMilkの扱い

現在の`CowState.readyMilk`を実際に使用します。

```text
生産完了
→ タンクに空きあり：タンクへ1
→ タンク満杯：readyMilkへ保持
→ 空きができたらタンクへ移す
```

同じ牛乳を二重に生成しません。

## 11. 酪農スタッフ

### 11.1 雇用

```text
650コイン
前提：牛舎建設済み
```

### 11.2 積載

```text
Lv1 8
Lv2 12
Lv3 16
```

### 11.3 仕事

```text
干し草を牧草地集配箱または倉庫から積む
→ 干し草台へまとめて補充

ミルクタンクから牛乳をまとめて回収
→ 牛舎集配箱または倉庫へ運ぶ
```

### 11.4 優先順位

```text
1. 干し草台が緊急水準以下
2. ミルクタンクが満杯に近い
3. 干し草台を目標量まで補充
4. 牛乳がbatch閾値以上
5. 待機
```

一個往復を禁止します。

## 15. Persistence

### 15.1 Schema

酪農ランタイムの完全状態を保存するため、

```text
schema 5 → schema 6
```

を許可します。

### 15.2 保存対象

- 牧草地購入
- 牧草地level
- 全牧草ノードstate/remaining
- 牛舎建設
- 牛数
- 牛ごとの生産状態
- readyMilk
- hayRack
- milkTank
- 工房建設/level/mode
- workshop input/output
- active cycle/reserved milk
- 酪農スタッフ
- 乳製品スタッフ
- 酪農集配ボックス
- ルート状態

### 15.3 Migration

schema 1〜5を維持します。

既存schema 5のdairy stateは可能な限り保持します。

牧草ノードがないschema 5：

```text
pastureLevelに応じたノードを生成
全ノードreadyから開始
```

既存のhay/milk/butter/cheeseは失いません。
