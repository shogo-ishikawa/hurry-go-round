# Hurry-Go-Round v0.2.0 — Visual Harvest Prototype

## Goal

Deliver one polished, repeatable farm loop: move to wheat, harvest automatically, carry up to 12 bundles, unload automatically at the barn, and return as crops regrow.

## Included gameplay

- A 2000 × 1400 bright 2.5D farm with two wheat plots, an oval circulation path, barn, delivery platform, pond, fences, trees, flowers, crates, barrel, sign, and layered ground detail.
- A directional female farmer assembled from original vector-like Phaser shapes, with a hat, ponytail, workwear, face, shadow, idle breathing, walking bob, and attached bundle stack.
- Two simultaneous movement interfaces:
  - continuous held-direction movement with WASD, arrow keys, or the dedicated touch joystick;
  - click/tap point movement to a bounded world destination.
- Manual held-direction input takes priority and cancels active point movement immediately.
- Short taps create destinations; drags and interactions with HUD or joystick regions do not.
- A visible pulsing world marker shows the current point-movement destination and disappears on arrival or manual cancellation.
- Bounded movement, smooth camera following, and responsive camera zoom.
- Thirty wheat nodes with ready, harvested, and growing visuals. Nearby crops harvest every 280 ms and regrow independently in 7.6–8.62 seconds.
- A 12-unit carrying limit, visible carried bundles, automatic one-at-a-time barn delivery every 180 ms, and conserved inventory.
- A camera-independent responsive HUD, staged non-modal tutorial, transient feedback, and one-time portrait suggestion.

## Input behavior

1. Holding a keyboard direction or the virtual joystick moves continuously for as long as the input remains active.
2. Clicking or tapping an ordinary farm location converts the screen point through the active world camera and starts automatic movement toward the bounded destination.
3. Clicking or tapping a new location replaces the previous destination.
4. Any keyboard or joystick direction cancels point movement and receives immediate priority.
5. Arrival uses a small radius so the farmer stops cleanly without oscillation or overshoot.
6. HUD, tutorial, version, movement-hint, and enabled joystick regions are excluded from point movement.
7. Blur, pointer release, resize, and orientation changes clear transient held input so movement cannot become stuck.

## Deferred

Customers, sales, currency, workers, automation, upgrades, land purchasing, saves, IndexedDB, PWA and offline support, service workers, audio, accounts, analytics, advertising, external APIs, multiple scenarios, animals, multiplayer, and barn capacity are intentionally excluded.

## Acceptance criteria

1. The field-to-barn loop works without action buttons.
2. Holding WASD, arrow keys, or the touch joystick produces continuous movement.
3. Clicking or tapping a farm point moves the farmer to that point and stops without overshoot.
4. Manual movement cancels an active point destination immediately.
5. UI and joystick interactions never create accidental world destinations.
6. Crops cannot award twice and use deterministic delta-time lifecycle logic.
7. Carried inventory never exceeds 12; unloading conserves total inventory.
8. Desktop, mobile landscape, and mobile portrait remain playable without fixed canvas dimensions.
9. The production site uses the `/hurry-go-round/` GitHub Pages base path.
