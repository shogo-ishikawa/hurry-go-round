# Hurry-Go-Round

明るい農場を走り回り、生産から販売までの循環を育てるブラウザーゲームです。**v0.9.6 — Contract Truthfulness & Final Release** は、正確な資源名と依頼ID、繰り返せる見送り、持ち物優先の契約納品を追加します。

## v0.9.0 のゲーム進行

1. 麦を収穫し、倉庫へ納品して市場で販売します。
2. **120コイン**で東の土地を購入し、24株のとうもろこし畑を開放します。
3. 東農地の拡張場所で、とうもろこし畑を **24 → 36株（220コイン）→ 48株（520コイン）**へ拡張できます。拡張に合わせ、とうもろこし集荷箱も **20 → 28 → 36個**へ増えます。
4. 納屋近くの看板で運搬かごを **12 → 18（60コイン）→ 24（140コイン）**へ拡張します。
5. 東の土地購入後、**240コイン**で南の鶏小屋を購入します。
6. とうもろこしを容量12の餌箱へ入れると、鶏3羽が4.5秒ごとに餌1個をたまご1個へ変換します。
7. 容量12の卵置き場から回収し、倉庫へ納品して市場で販売します。
8. 東農地で160コインの収穫スタッフと240コインの運搬スタッフ、鶏小屋で300コインの飼育スタッフを雇えます。
9. 売り切れが12秒続いた先頭のお客さんは購入をあきらめ、次のお客さんへ順番を譲ります。
10. 納屋近くの契約板で決定的に生成される依頼を受注し、契約出荷場から持ち物、次に倉庫の商品を納品してコインと評判を得ます。
11. 農場はIndexedDBへ自動保存され、タイトル画面から続行、JSON書き出し・読み込み、設定を利用できます。

運搬かごは麦・とうもろこし・たまごを同時に保持し、合計容量を共有します。倉庫では麦→とうもろこし→たまごの順を循環して1個ずつ納品します。倉庫と市場は麦・とうもろこし・たまごを資源別に管理し、市場棚は各8個です。販売価格は麦2、とうもろこし3、たまご5コインです。既存の収穫・運搬スタッフは引き続き**麦専用**です。

## 操作方法

- **E / Space:** 契約板または農場運営所の範囲で画面を開きます。
- **Escape / P:** 一時停止・管理メニューを開きます。
- **WASD / 矢印キー:** 手動移動。クリック目的地を解除します。
- **固定ジョイスティック:** キーボードと同じ優先度の手動移動です。
- **短いクリック / タップ:** 指定地点まで移動し、到着すると停止します。
- **ジョイスティック外のドラッグ:** 押し始めを原点として方向を決め、押している間はその方向へ進み続けます。原点付近へ戻すと一時停止し、離すと目的地を残さず即時停止します。
- 収穫、納品、補充、購入、給餌、卵回収は接近または範囲内での滞在により進行します。未購入地へはどの入力方法でも侵入できません。

## 看板・案内と日本語UI

施設名は木製看板または建物プレートへ収め、地面へ裸の文字を置きません。詳細案内は中距離で背景付きパネルに一つだけ表示し、操作範囲へ入ると消えます。同じ警告を毎フレーム生成しません。公開UIはゲームタイトルとバージョンを除いて日本語で、資源名・施設名・警告は `src/game/config/localization.ts` に集中管理しています。

HUDは持ち物、資源別倉庫、資源別売り場、麦の自動化、解放後の鶏小屋を表示します。1920×1080、1440×900、844×390、390×844、320×568を対象に予約入力領域を計算し、HUD上から移動を開始しません。

## とうもろこし・養鶏自動化

とうもろこし収穫スタッフは、実際に準備完了の株へ移動し、レベルに応じて **5・6・8個**までまとめて収穫してから集荷箱へ運びます。畑を拡張すると株数だけでなく収穫間隔も短くなり、スタッフが待機しにくくなります。

とうもろこし運搬スタッフは、集荷箱で **8・10・12個**までまとめて積み込み、長い往復を一個運搬に使いません。生産が一時的に途切れた場合は短時間だけまとめ待ちを行い、その後に現在の積載分を倉庫へ運びます。

飼育スタッフは、レベルに応じて **6・8・10個**を一往復で扱います。餌不足時は倉庫で目標量までのとうもろこしをまとめて積み、餌箱へ一括補充します。卵は卵置き場でまとめて回収し、倉庫へまとめて納品します。餌箱が途中で満杯になった場合、余ったとうもろこしは倉庫へ返します。

## 加工場と生産計画

東の畑と鶏小屋を解放すると **800コイン**で加工場用地を購入できます。製粉機（350コイン）は麦2→小麦粉1、とうもろこし2→コーンミール1を加工し、ベーカリー（850コイン）は小麦粉1＋たまご1→パン1、小麦粉1＋コーンミール1＋たまご1→コーンブレッド1を生産します。機械は入力・出力バッファと決定的な生産サイクルを持ち、バランス・市場優先・契約優先・加工優先の方針で在庫を保護します。製粉スタッフと製パンスタッフは一種類の商品をまとめて運びます。

南東の予定地で購入・建設の進捗が表示されます。搬入口では対応する持ち物を1個ずつ移し、受取口では空き容量の範囲で完成品を回収します。管理板へ近づいて **E / Space** またはタッチボタンを押すと、ゲームを一時停止して入力・出力・稼働状態を確認し、運転モードを変更できます。

## 技術構成

- TypeScript（strict）
- Phaser 3
- Vite
- Vitest
- ブラウザーAPI（追加ランタイム依存、外部画像、CDN、外部サービスなし）

```text

├── art/          共有パレット、地形、短時間エフェクト

├── input/        ジョイスティック、レスポンシブ予約領域
├── logic/        Phaser非依存の資源・土地・畜産・市場・契約・自動化ロジック
├── persistence/  IndexedDB、検証、移行、入出力
├── routes/       従業員の固定移動経路
├── scenes/       システム調整とカメラ固定HUD
├── state/        資源別在庫、土地、畜産、経済の正規状態
└── systems/      市場、拡張、強化、雇用、各種自動化
```

## v0.8.0 の運営機能

上段の旧麦畑へ移設した **研修小屋** の入口で E / Space または画面の操作ボタンを押すと、5人のスタッフの雇用状況、作業状態、レベル、正確な雇用・研修費用を確認できます。現地の雇用パッドも引き続き利用でき、どちらも同じ取引判定を使います。とうもろこし収穫・運搬スタッフと飼育スタッフは、作物・集荷箱・倉庫・餌箱・卵置き場の間を実際に移動します。

セーブ形式はschema 8です。v0.9.3では牧草地（1,000コイン、24→36→48区画）、牛舎（1,400コイン、最大3頭）、牛乳、乳製品工房、バター、チーズ、酪農スタッフを追加します。schema 3の加工・契約・スタッフ状態を保ったまま、集配ネットワークを追加します。schema 2の資源・契約・とうもろこし畑レベルを保ったまま、4種類の加工品と加工場状態を追加します。既存のschema-2セーブでは、とうもろこし畑の拡張レベルが未記録の場合にレベル0として読み込みます。v0.7.0の有効なschema-1セーブとJSON書き出しも、起動または読み込み時に自動移行されます。

## v0.9.3 の牧草地と酪農

### v0.9.4 collection runtime

After the processing yard is unlocked, the collection hub and the wheat, corn, and egg collection boxes can be built in the world. Stand at a box to deposit matching cargo or recover it from the lower pickup side. Open the hub with **E** or its touch button to hire/train the courier, change routing, inspect capacity, or perform an emergency barn transfer. The courier moves visibly between facilities and sends batches to a usable processing machine, falling back to the barn when processing cannot accept them.

## v0.9.6 契約の信頼性と最終リリース

契約は全資源を `RESOURCE_DEFINITIONS` の日本語名で表示し、`依頼 #000123` 形式の安定したIDで区別します。見送りは選んだ候補だけを即時に新IDへ交換し、旧式の30秒待ち時間はschema 8の読み込み時にゼロへ正規化します。進行中の各資源には必要数・納品数・持ち物・倉庫・不足数を表示し、出荷場は持ち物を優先してから倉庫を使います。中止時は納品済み数量を倉庫へ正確に返し、最後の1個で報酬・ボーナス・評判・統計を一度だけ確定します。

## v0.9.7 Phase 2 — 一括出荷と売上回収

契約出荷場へ入ると、必要な商品を持ち物優先、倉庫次点で一括納品します。不足時は利用できる全数量と正確な残数を一度に確定し、充足時は同じ操作で報酬まで一度だけ受け取ります。出荷場を離れるまで自動納品は繰り返しません。売上台では未回収売上を一度の接触で全額回収します。公開版とセーブ形式は引き続き v0.9.6 / schema 8 です。
